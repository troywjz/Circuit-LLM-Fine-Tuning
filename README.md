# Circuit LLM Fine-Tuning

本项目探索通过小模型微调辅助电路需求澄清与设计意图整理，同时评估通用对话、多轮能力和私有部署成本。V0 聚焦需求到 Circuit Design Intent，不包含自动生成原理图、PCB 或生产验证。

两轮 QLoRA 训练、停句修复后的开发对照和冻结 50 题最终诊断均已完成。最终诊断中，FT-revised step 30 相对 Base 的领域均分提高 3.56 分，通用均分降低 5.75 分，领域硬错题增加 2 题；未达到开发门槛，仅作诊断，不推荐部署，也不能称为整体微调成功。详见[修订开发对照](docs/修订开发集对照.md)和[最终诊断对照](docs/最终诊断对照.md)。

早期推理的回合结束标记不完整，旧分数仅保留为诊断记录，见[停句配置说明](docs/停句配置修复说明.md)和[旧记录](docs/首轮开发集对照.md)。

首轮数据含 14 条领域来源改写与 16 条自编通用、多轮情境；通用情境也包含技术材料说明。完整来源池仍有 92 条领域训练来源候选、20 条通用情境和 19 条验证来源候选，不能视为全部已生成或可训练。详见[Demo 运行说明](docs/Demo运行说明.md)。

dev16 与 final50 已冻结原样。基座开发集记录见 [基座开发集记录](docs/基座开发集记录.md)。

快速入口：[Demo 运行说明](docs/Demo运行说明.md)、[运行与试训](docs/运行与试训.md)、[数据整理程序](docs/数据整理程序.md)、[项目管理基线](项目管理基线.md)、[训练数据规则](docs/训练数据规则.md)与[评测规则](docs/评测规则.md)。
