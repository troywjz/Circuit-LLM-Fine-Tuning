# Circuit LLM Fine-Tuning

本项目探索用低显存QLoRA微调电路需求分析小模型。实验范围包括需求澄清、方案比较、接口规划和风险提示；不包含自动原理图生成、PCB设计或生产验证。

## 当前结果

正式实验使用1,000条经人工复核的中文对话，在RTX 5060 Ti 8GB上完成Qwen3.5-4B QLoRA训练。100道终测题中，微调模型的百分制均分比基座模型高4.81分，严重错误答复从40条降至15条。完整过程、九模型得分和分数说明见[正式实验结果](docs/正式实验结果.md)。

这组结果覆盖文字需求分析和方案规划。实际电路仿真、器件测量和生产验证仍属于后续工作。
