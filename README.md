# Circuit LLM Fine-Tuning

本项目探索通过小模型微调辅助电路需求澄清与设计意图整理，并评估私有部署和成本；同时关注通用对话与多轮能力的保留。

当前有两类小规模链路证据：旧版 8 条玩具对话、10 步训练；以及新版 5 条人工审核中文样例、3 步 QLoRA 训练。新版记录到 train loss 3.463、峰值 allocated 3.311 GiB，adapter 可在新进程重载并生成回答；该回答达到 128 token 上限，标记为截断。它们只证明有限训练与重载链路可运行，不证明领域效果、正式训练收益或生产能力。详见 [Demo 运行说明](docs/Demo运行说明.md)。

V0 聚焦需求到 Circuit Design Intent，不包含自动生成原理图、PCB 或生产验证。

快速入口：[Demo 运行说明](docs/Demo运行说明.md)、[运行与试训](docs/运行与试训.md)、[数据整理程序](docs/数据整理程序.md)、[项目管理基线](项目管理基线.md)、[训练数据规则](docs/训练数据规则.md)与[评测规则](docs/评测规则.md)。
