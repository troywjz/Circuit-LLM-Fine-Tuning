# Circuit LLM Fine-Tuning

本项目探索通过小模型微调辅助电路需求澄清与设计意图整理，并评估私有部署和成本；同时关注通用对话与多轮能力的保留。

当前已跑通一次有限流程：使用 8 条玩具对话进行 10 步训练、保存 adapter，并在新进程中重载。默认基座为 Qwen3.5-4B，源码包含基于 Unsloth 与 PEFT 的 LoRA/QLoRA 路径。这只证明试训与重载链路可运行；正式数据上的微调收益和生产级长上下文能力尚未验证。

V0 聚焦需求到 Circuit Design Intent，不包含自动生成原理图、PCB 或生产验证。

快速入口：[运行与试训](docs/运行与试训.md)、[项目管理基线](项目管理基线.md)、[训练数据规则](docs/训练数据规则.md)与[评测规则](docs/评测规则.md)。
