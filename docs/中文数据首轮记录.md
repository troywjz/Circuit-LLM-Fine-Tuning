# 中文数据首轮记录

## 冻结范围

**SOURCE_FACT**：首轮冻结 30 条中文训练对话：14 条来自 Electrical Engineering Stack Exchange 的领域问答改写，16 条为项目自编的通用与多轮情境。通用情境中包含技术材料说明，不应理解为 16 条纯日常闲聊。原先约 14 条领域加 20 条通用的设想调整为 14+16，以尽快获得反馈；未补造其余 4 条。

材料不是教师原样答案。领域题经教师改写后，由主 Agent 作实质工程修订，重点修正事实和约束；通用情境为项目自编。作者、原帖链接及适用的 CC BY-SA 版本元数据保留。源码使用 MIT 许可不会自动覆盖第三方资料或教师输出。
