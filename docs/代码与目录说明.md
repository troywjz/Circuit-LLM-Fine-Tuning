# 代码与目录说明

当前公开代码集中在 `scripts/`：

- `qwen35_common.py`：统一本地模型与 adapter 检查、路径解析和加载逻辑。
- `qwen35_infer.py`：从本地基座模型执行单轮推理，也可加载 adapter。
- `qwen35_qlora_smoke.py`：使用内置玩具对话执行短步数 QLoRA/LoRA smoke，并保存 adapter 和运行摘要。

运行中可按需产生 `models/`（本地模型）、`experiments/`（试验输出）等目录。这些内容属于本地输入或产物，不是源码交付。可通过 `--model-path` 覆写模型目录；本机还可选用私有本地配置机制，公共说明见[运行与试训](运行与试训.md)。

smoke 脚本用于确认一次训练、保存和重载流程，不是 Benchmark。其默认 512 token 序列长度是短流程配置，不能据此推断生产上下文能力。项目 V0 输出边界是需求到 Circuit Design Intent，不包含自动原理图、PCB 或生产验证。
