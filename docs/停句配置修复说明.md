# 停句配置修复说明

本机模型缺少生成配置，运行时只把 `248044` 当作结束标记；聊天模板使用的回合结束标记是 `248046`。回答写完一轮后可能仍继续生成下一轮角色或重复文本。这会影响多轮历史、截断、耗时和评分，因此旧的本地对照暂时只作为诊断记录，不能据它判断微调增益或退步。

[Qwen 官方生成配置](https://huggingface.co/Qwen/Qwen3.5-4B/blob/c7429d5a8ed57f4a9cfdaf1af76a8943eba0ae97/generation_config.json) 包含两个结束标记。两个本地推理入口现在合并模型 EOS、tokenizer EOS 与聊天回合结束标记，并显式传给生成函数；检测停止原因也使用同一名单。新增协议版本和配置哈希，旧输出不能混入新运行。

本次修复不改基座文件、训练数据或已保存的适配器。训练标签原本已经包含正确的回合结束标记，已有权重可继续使用。基座与微调模型需要在同一新停句规则下重新对照；独立 API 参照不受本地问题影响。实测结果完成后再更新效果结论。

**SOURCE_FACT**：54 项离线检查通过；一条真实短回复生成 28 tokens，末 token 为聊天回合结束标记，正常停止。较长开发题仍可能达到 1024 输出上限，修复不保证消除所有截断或计算错误。
