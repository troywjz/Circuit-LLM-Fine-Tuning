# 基座开发集记录

日期：2026-10-11。

本轮只建立微调前的对照，不证明微调收益。模型为 Qwen3.5-4B，4-bit 加载，关闭 thinking，greedy 解码；上下文 4096，每轮最多生成 1024 tokens。题目与评分要点在运行前固定。

| --- | ---: | ---: | ---: | ---: | ---: |
| 电路领域 | 12 | 47.92 | 0 | 10 | 11 |
| 通用工作对话 | 4 | 76.25 | 3 | 0 | 0 |

这些是自编合成诊断题，含同类任务的参数变体，不是官方 Benchmark。Luna 给盲评草稿，主 Agent 按固定要点复核；每题按适用维度归一化。80分、每维至少1分且无实质错误才算通过。

领域题暴露了 LDO 压差方向、ADC 分压、UART线路开销及平均电流单位等错误，也大量重复题面。11题含输出截断，因此分数包含当前输出预算下的完成度，不能当成模型能力上限。

另外一题放宽到最多4096生成tokens后，用1998tokens完整结束；完成度改善，但表中一个阻值的上升时间及末尾电流约束仍有错误。它只用于诊断，未混入主评分。

正式中文领域训练、最终独立测试和 Claude Opus 5.5 API参照尚未完成。后续将用相同本地配置比较 Base 与 FT，同时记录截断和硬错误；如果主要改善来自更简洁的表达，会直接说明。
