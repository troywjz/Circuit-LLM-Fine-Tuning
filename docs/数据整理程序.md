# 数据整理程序

本页说明当前仍在使用的两个整理入口。正式数据流程和审核要求见[正式实验数据准备](正式实验数据准备.md)。正式实验已完成1,000条训练对话的整理与审核。

## 从来源包生成训练候选

`scripts/build_demo_data.py` 读取来源包，按来源编号、样本编号和分组编号检查重复，然后生成中文对话候选。先查看参数，再对输入运行预检：

```powershell
python scripts/build_demo_data.py generate --help
```

正式生成前使用 `--dry-run` 检查来源、样本数和输出目录。生成的内容始终作为待审候选；内容审核通过后，才可汇入训练集。遇到请求结果不明时，先核对本地记录，再决定后续处理。

## 整理独立资料

`scripts/prepare_dataset.py` 用于把结构化来源整理成待审样本。默认输入为 UTF-8 JSONL；支持先检查输入、导出整理任务和生成候选：

```powershell
python scripts/prepare_dataset.py --dry-run
python scripts/prepare_dataset.py --export-prompts
```

输入记录保留来源编号、分组、任务、学生题干和数据拆分。训练、开发和终测来源按原题、项目或对话关系隔离。输出候选初始状态为待审核，程序检查格式与重复项，不代替内容核对。

## 审核与保存

- 每条样本保留来源链接、版本、作者、许可及必要的修改说明。
- 逐条检查中文表述、任务约束、工程事实和安全条件；有疑问的样本进入待核清单。
- 原始来源、生成回复、审核记录和运行配置保存在 Git 忽略的本地目录。
- 公开代码采用MIT许可；训练数据、原始来源、生成回复、审核记录和运行配置保存在Git忽略的本地目录。本仓库只公开代码、实验结果和文档。
