# 数据整理程序

这里记录上一轮 Demo 的数据整理方式。正式实验的准备流程见[正式实验数据准备](正式实验数据准备.md)。Demo 使用 `scripts/build_demo_data.py` 整理来源包并生成候选；运行顺序和审核要求见 [Demo 运行说明](Demo运行说明.md)。`scripts/prepare_dataset.py` 仍可用于其他资料整理任务。首轮未使用 SchGen 素材。

## 当前 Demo 数据

完整来源池仍有 92 条领域训练来源候选、20 条通用情境和 19 条验证来源候选；来源数量不等于已生成或已批准的中文训练对话数，也不代表全部可训练。首轮已冻结 30 条中文对话：14 条 Stack Exchange 领域来源改写、16 条自编通用/多轮情境，含技术材料说明，不是纯日常闲聊。原先约 14+20 的设想调整为 14+16，以尽快获得反馈；未补造其余 4 条，完整来源池以后再扩充。详见[中文数据首轮记录](中文数据首轮记录.md)。

主 Agent 审校和本地 Qwen tokenizer assistant-only 检查通过：样本长度 69–378 tokens，合计 7,288 tokens，其中 assistant labels 合计 4,341 tokens，无截断。教师改写经主 Agent 实质工程修订；Stack Exchange 原作者、原链接及适用许可版本元数据保留。源码 MIT 不会自动覆盖第三方资料或教师输出。首轮没有中文 validation 数据，使用冻结 dev16 选择 checkpoint。后续诊断对照的结果见[最终诊断对照](最终诊断对照.md)。

教师 API 已恢复，首轮中文数据已完成审校。少量返回有正文截断或 JSON 引号问题，分别剔除或经人工核对后离线修复，原文保持不变。教师产出是草稿，训练材料由教师改写和主 Agent 的实质修订共同形成，并非教师原样答案；完整回复不等于内容正确。

`build_demo_data.py generate` 支持 `--review-notes`，用于读取本地私有 JSON 校注文件。文件仅包含 `common_note`、`topic_notes`、`sources` 三个顶层字段；其中来源元数据不进入教师 prompt，topic 工程校注用于补充对应领域背景。该功能不改变来源包中的许可与作者记录。

```json
{
  "common_note": "通用写作或证据边界提示",
  "topic_notes": {"adc": "该 topic 的工程校注"},
  "sources": []
}
```

生成器只剥除包住整段回复的单个完整外层 JSON 围栏，不从任意正文中抽取 JSON。若正文中途截断或结构不完整，停止并交主 Agent 审校，不补造缺失内容。未转义引号可由人工判断后作机械修复，但必须保留原始返回并审查修复内容。不要把模型输出直接当成正确答案或训练许可。

示例：

```powershell
python scripts/build_demo_data.py generate --input 本地资料/Demo-V1/数据/train_sourcepack.jsonl --approval-file 本地资料/Demo-V1/数据/generation_approval.json --review-notes 本地资料/Demo-V1/数据/review_notes.json --outdir 本地资料/Demo-V1/数据 --limit 20 --dry-run
```

去掉 `--dry-run` 才会发起真实请求；批准来源和试跑数量应按首轮实际范围填写。完整参数及导出命令见 [Demo 运行说明](Demo运行说明.md)。来源许可须逐项核对并保留原作者、原帖链接及适用许可版本；Stack Exchange 的公开说明见[许可页面](https://electronics.stackexchange.com/help/licensing)。

## 通用整理流程：prepare_dataset.py

该流程保留给独立的资料整理工作。程序只生成待审候选，不核验许可、器件事实或物理结果。当前 API 服务已有成功回复，但这不构成任一批次完整或生成质量合格的结论。

将根目录 `.env.example` 复制为本机 `.env` 并按服务配置填写变量。模型名称不决定接口协议；兼容网关的实际接口和模型 ID 应以服务方支持为准。私有输入默认位于 `本地资料/数据准备/原始资料输入.jsonl`，候选输出位于 `本地资料/数据准备/候选输出/`；`examples/资料样例.jsonl` 仅为自编格式示例。

```powershell
python scripts/prepare_dataset.py --dry-run
python scripts/prepare_dataset.py --export-prompts
python scripts/prepare_dataset.py --limit 3
```

第一条只检查输入并展示任务数；第二条导出私有任务包；第三条调用已配置的 Teacher。`--check-config` 只报告缺少哪些字段，不显示配置值。输入、输出目录和环境文件可用 `--input`、`--output-dir`、`--env-file` 覆盖。

输入是 UTF-8 JSONL，每行记录来源、项目和分组、split、任务、学生题干与来源。split 为 `train`、`validation`、`test`；项目、家族或同源样本不得跨集合。英文原文及审核元数据单独保存，不把参考答案或评分要点拼入学生题干。翻译和格式校验均不等于工程事实核验；所有候选初始待审，`training_eligible` 为 false。

确认资料许可覆盖处理与保存用途，并按实际账户、服务和用途确认 Teacher 输出用于其他模型微调是否获准。协议兼容性不代表输出可用于微调其他模型，也不替代原始资料授权。真实输入、返回、候选、review notes 与 `.env` 都是本机私有资料，不应加入公开仓库。
