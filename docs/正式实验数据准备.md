# 正式实验数据准备

## 当前状态

正式训练集共1,000条中文对话：电路领域901条、通用99条。来源统计为Stack Exchange 811条、SchGen 85条、OASST1 50条、Open Schematics 5条和项目自编49条。QLoRA训练与终测已完成，实验结果见[正式实验结果](正式实验结果.md)。

终测使用100道独立题（电路领域74道、通用26道）；10道开发题用于选定训练步数。训练、开发和终测题分别管理，终测题在结果汇总前保持冻结。

数据发布状态：**本地审阅版，许可与StackExchange署名待核，未上传。** 原始来源、教师生成回复、审核材料和训练文件保存在Git忽略的本地目录。

## 可复用的数据流程

1. **确认来源**：记录来源名称、公开链接、版本或行号、作者、许可和用途范围。来源许可未核清时，先放入待核清单。
2. **去重与分组**：按原题、项目、对话树或派生关系建立来源组，防止同源内容跨训练、开发和终测集合。
3. **整理成对话**：从许可范围内的材料生成中文多轮样本，保留任务需要的条件、接口和风险信息。教师原始回复单独保存。
4. **人工审核**：逐条核对题目是否完整、回答是否忠实来源、工程事实是否有依据、条件是否表达清楚。通过审核后再进入训练集。
5. **冻结开发与终测**：训练开始前确认数据哈希、来源隔离和题目清单。开发集用于选择训练步数；终测只用于最终比较。
6. **训练前检查**：验证JSONL格式、消息角色、空内容、重复来源和分词长度。统计报告保留样本数、数据来源和审核状态。

## 文件格式

训练样本使用JSONL，每行一条记录，`messages`中按顺序保存`user`与`assistant`消息。来源、许可和审核信息放在训练内容之外；训练程序只读取对话文本。原始来源和教师回复不放入公开仓库。

## 公开发布

项目代码采用MIT许可；外部数据和生成内容按各自来源许可处理。公开数据前逐条确认来源归属、作者、许可证和必要的修改说明，再生成专用发布文件。当前训练集保留在本地审核版，发布范围仍待许可与署名核对。

数据整理程序入口见[`scripts/build_demo_data.py`](../scripts/build_demo_data.py)和[数据整理程序说明](数据整理程序.md)。
