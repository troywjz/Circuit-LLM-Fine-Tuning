# 运行与试训

脚本从本地模型目录加载模型，不负责下载权重。请先按当前平台查阅 [Unsloth 安装指南](https://unsloth.ai/docs/get-started/install)及对应的 [PyTorch 安装指南](https://pytorch.org/get-started/locally/)，再准备兼容的 Python 环境和本地模型文件。不要把某一台机器的依赖快照当成通用安装步骤。

以下命令在项目根目录执行。模型路径可用 `--model-path` 覆写；公共示例使用相对路径 `models/Qwen3.5-4B`。脚本也支持可选的私有本地配置机制：环境变量 `CIRCUIT_MODEL_PATH` 优先，其次读取本机配置，最后回退到项目内默认目录。配置只用于指定模型路径，不应纳入源码仓库。

```powershell
python scripts/qwen35_infer.py --model-path models/Qwen3.5-4B
python scripts/qwen35_qlora_smoke.py --model-path models/Qwen3.5-4B --steps 10 --seq-length 512
python scripts/qwen35_infer.py --model-path models/Qwen3.5-4B --adapter-path experiments/qlora/checkpoints/qwen35-4b-smoke/adapter
```

第一条运行基座推理；第二条用内置玩具对话做短步数 smoke 并保存 adapter；第三条在新进程中加载基座和 adapter。默认 `seq-length=512`、推理 `max-new-tokens=96` 都是短 smoke 设置。它们不代表生产窗口、稳定长上下文、正式训练或领域能力提升。正式试训前仍需审核真实数据、确认消息模板与监督范围，并先建立基线和冻结评测。

模型权重、训练数据与输出目录由使用者自行准备和管理。模型及数据依其原授权使用；不要将原始数据或权重加入源码仓库。
